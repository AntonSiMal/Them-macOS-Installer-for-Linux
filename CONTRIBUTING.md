# Contribuir a macOS Tahoe Installer

¡Gracias por tu interés en contribuir! Este documento te guiará en el proceso.

## 🐛 Reportar bugs
1. Verifica que el bug no esté ya reportado en [Issues](https://github.com/AntonSiMal/Them-macOS-Tahoe-Installer-for-Linux/issues)
2. Abre un nuevo issue con la etiqueta `bug`
3. Incluye:
   - Tu distribución y versión (ej: Ubuntu 24.04)
   - Entorno de escritorio (GNOME/Cinnamon/XFCE)
   - Versión de GNOME Shell: `gnome-shell --version`
   - Pasos para reproducir el problema
   - Capturas de pantalla si es posible

## 💡 Sugerir mejoras
1. Abre un issue con la etiqueta `enhancement`
2. Describe la mejora y por qué sería útil

## 🔧 Enviar código
1. Fork el repositorio
2. Crea una rama para tu cambio: `git checkout -b feature/nombre-de-tu-feature`
3. Prueba tus cambios en al menos un entorno (GNOME, Cinnamon o XFCE)
4. Envía un Pull Request describiendo tus cambios

## 📝 Estilo de código
- Usa `bash` con shebang `#!/bin/bash`
- Comenta las secciones importantes del script
- Usa colores para la salida en terminal
- Maneja errores con mensajes claros para el usuario
- Mantén las funciones pequeñas y con un propósito único

¡Gracias por ayudar a mejorar este proyecto!
